一、原本已經安裝 V1.0.0

  1. 先暫停活動並備份。在原後台關閉正式活動與試玩，暫停發碼與核銷。備份網站程式、app/config.php，以及設定檔中 data_dir 指向的整個私有資料夾。
  2. 上傳 UPDATE 更新包至原遊戲目錄。在 cPanel File Manager 解壓縮並覆蓋同名檔案。index.php、api.php、app/ 與 assets/ 應維持原本層級。
  3. 保留原設定與資料。更新包不包含 app/config.php、install.php、setup-key.php，也不包含任何正式帳號或優惠券資料。不要刪除私有資料夾，不要執行安裝程式。
  4. 關閉舊分頁後重新開啟。桌機可使用 Ctrl+F5；程式與樣式的快取版本已更新為 v=1.1.0。
  5. 驗收後再開放活動。先開啟試玩，確認相同圖案消除、不同圖案蓋回，全部配對後才顯示獎勵；確認原會員與舊優惠券仍能查看，再啟用正式活動。完成後刪除上傳的 ZIP。
舊資料會如何處理？

原會員、管理員、活動設定、獎項、遊戲碼及優惠券沿用。舊版已領獎的訂單不會再送一張券；尚未領獎的有效遊戲碼啟動時建立新的配對牌局。

管理員「重新發碼」會重置該筆尚未領獎的配對進度並作廢舊碼。此更新包只能套用於本專案，不可套用到其他遊戲或公司系統。

二、尚未安裝：全新安裝

  1. 使用 FULL 完整安裝包，建立獨立目錄，例如 public_html/kyuc10/，上傳並解壓縮；index.php 應在第一層。
  2. 主機使用 PHP 8.2 以上與 HTTPS。不需要 MySQL、Composer 或 npm。
  3. 編輯 setup-key.php 的 return '';，將空字串換成自己產生、至少 24 字元且不公開的隨機安裝金鑰。
  4. 使用 HTTPS 開啟遊戲目錄中的 install.php，輸入相同金鑰，建立自己的管理員帳號與密碼。
  5. 私有資料夾必須放在 public_html 與所有其他網站公開根目錄之外。使用安裝頁建議的絕對路徑，並確認該位置沒有被其他網域對外公開。
  6. 安裝完成後刪除 install.php、setup-key.php 與上傳的 ZIP。進入 admin.php 設定門市、聯絡方式與獎項。

新安裝預設正式活動暫停、免費試玩開啟。確認成本、券面使用條件及活動設定後，再對外開放。全新安裝不可套用其他專案的設定檔或私有資料夾。

三、遊戲紀錄與獎勵

一次翻完兩張卡片計為一次配對嘗試；只翻第一張或重複點擊同一張，不會額外增加次數。時間從翻開第一張開始計算，包含離開頁面的時間，不是倒數計時。遊戲碼本身仍有原本的到期日。

正式進度逐次保存，可重新整理或換瀏覽器登入同一帳號續玩；網路中斷時使用「重新載入遊戲進度」，會取回已保存狀態。試玩進度只存於目前 PHP 工作階段，可重新洗牌，不是永久會員紀錄。

全部 6 組配對完成後，才由後端按原獎項權重發放並保存優惠券。獎勵仍限下一筆符合條件的訂單使用。重複完成請求取回同一張券，不重複扣獎品庫存。

四、仍然是獨立系統

不連接 WordPress、POS、購物車、付款或其他會員系統。門市須人工確認真實消費、付費杯數與帳號後發碼，再於下次消費時人工核銷。

本版使用單一主機的私有檔案儲存，不是 MySQL。定期備份整個私有資料夾；previous.php 只是一份上一狀態備份，不能取代獨立備份。發生權限或路徑問題時，請由主機商確認 PHP 的檔案擁有者與寫入權限，不要將資料搬到公開目錄或設為 777。
